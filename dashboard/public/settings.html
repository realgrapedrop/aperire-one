 StatusWhether that node is on the fleet’s setting
  • IN SYNC: it reports the fleet’s provider, model and key.
  • BEHIND: it reports something else, or it missed the last change. Bring it up to date.
  • NO MODEL: its Advisor runs but nothing is sealed on it, so it cannot answer.
  • NO CREDENTIAL: a model is chosen but its key is not on this host, which is where a host restored from a backup often lands, since the key is sealed to the host that made it and does not travel with the rest of a backup. Bring it up to date to reseal one.
  • UNREAD: it did not answer, so it said nothing about itself.
  • NO ADVISOR: nothing to configure there. On this host, no Advisor is installed. On a node, this dashboard holds no Advisor address for it, which is either because it runs none (the add-on is optional) or because its fleet registry row was written without one.
  • UNKNOWN: no model is set for the fleet yet, so there is nothing to hold it against.
 ArmWhether root has opened a sealing window there

Sealing writes a root-owned file, which the dashboard cannot do on its own. Root opens a fifteen-minute window first, with one line on this host; the seal spends it.

  • ARMED 12m: a window is open, twelve minutes left. Seal now.
  • not armed: no window. The resting state, what every node reads almost all the time, and what it reads again once a seal has spent its window. Not a fault.
  • unread: this dashboard could not read the node’s arm state. Its dashboard did not answer, or runs a build without the arm route.

This column is shown while a change is being made, which is the only time the window matters.
